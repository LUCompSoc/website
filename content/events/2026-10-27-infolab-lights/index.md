In the session we will go over Programming the InfoLab Lights. We'll give you an overview of the lights and how they work, then go over using the playground and creating patterns. We can also guide you through making a pull request to get your pattern on the building.

The programming will be in JavaScript but most of what you need is essentially the same as C so you should be alright if you have never used JavaScript before

The Playground (see Resources) contains an environment where you can write your patterns and see how they run on the screen. To get it on the building, you should check out the github and follow the instructions to submit a pull request.

You can also see the source code of all the patterns on the github.
